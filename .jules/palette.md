## 2024-09-20 - Adding Accessible Loading States and Alerts\n**Learning:** Next.js async interactive buttons (like report/favorite) need explicit `aria-busy` states and role="alert" on error messages to be truly accessible to screen readers, especially since network delays can happen.\n**Action:** Always add `aria-busy` to async loading buttons and `role="alert"` to async error messages in standard BPT components.
